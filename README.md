# Portfolio

## Available Scripts

In the project directory, you can run:

### `npm start`

Starts the Vite development server. Open the URL shown in the terminal.

### `npm test`

Runs the Vitest test suite in watch mode.

### `npm run build`

Builds the production site into `dist`.

### `npm run deploy`

Builds the site and deploys `dist` to GitHub Pages.
